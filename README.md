# CampusNotes

CampusNotes is a simple web application for college students.

## Features
- Add notes
- View notes
- Delete notes

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project helps students manage their academic notes.

## Future Improvements
- Save notes permanently
- Add search functionality
- Add student login
